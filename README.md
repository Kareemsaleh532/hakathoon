# منصة هاكاثون الابتكار البيئي والمناخي (Hackathon Platform)

منصة متكاملة لإدارة فعاليات الهاكاثون (البيئة والتغير المناخي) تم بناؤها باستخدام Next.js.

## المميزات الرئيسية
- **تسجيل الفرق والمتسابقين:** تسجيل المشاركين وتوزيعهم على الفرق المعتمدة من قبل الإدارة.
- **إدارة التحديات البيئية:** استعراض وإضافة التحديات البيئية والمناخية ومخرجاتها المطلوبة.
- **بوابة التسليم المقيدة:** لا تفتح بوابة تسليم المشاريع إلا بقرار مباشر من الادمن، مع ربط المشروع تلقائياً بالفريق المسجل.
- **نظام التحكيم والتقييم:** تقييم متقدم للمشاريع وفق معايير قابلة للتخصيص من قبل الادمن مع احتساب المعدل وإضافة التغذية الراجعة.
- **لوحة تحكم الادمن:** إدارة الفرق، التحديات، معايير التحكيم، الحكام، المتسابقين، وإمكانية تصفير البيانات للوضع الافتراضي.
- **تصميم قياسي:** استخدام ألوان مسطحة واضحة بدون توهج أو تدرجات لونية، مع خط Fira Sans الموحد.
